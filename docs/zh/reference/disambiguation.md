# 消歧规则

Simy 在少数几个符号上复用了含义。本页把「到底按哪种含义解释」的规则集中列出，读代码时不必再猜。

| 特性                       | 判定方式                                                                                                      |
| :------------------------- | :------------------------------------------------------------------------------------------------------------ |
| `{ }`                      | 代码块；但紧跟在 `=` 之后是映射 / 结构字面量，位于命令参数位则是原始 [NBT](/zh/reference/commands#nbt-逃生舱) |
| 控制流头部后的 `{`         | 必须与头部同一行；`{` 另起一行会开始一条新的裸块语句                                                          |
| `< >`                      | 类型位置是泛型参数（`list<num>`）；表达式位置是比较运算符                                                     |
| 紧贴标识符的 `( )`         | 函数调用                                                                                                      |
| 空白之后的 `( )`           | 只能是坐标 / 向量原子（见[函数](/zh/reference/functions#调用函数)）                                           |
| `with(…)`                  | 命令[选项块](/zh/reference/commands#命令选项)                                                                 |
| `\|>`                      | **续行标记**：以 `\|>` 开头的行延续上一条语句。它绝不是运算符，也不同于 `\|\|`                                |
| `#[…]`                     | 装饰下一行的[属性](/zh/reference/functions#入口点)，绝不是注释                                                |
| `$name`                    | 命令中是变量引用；字符串中是内插                                                                              |
| `.scores.x`                | 用户 objective；其他 `.name` 都是领域属性                                                                     |
| `at` `as` `unless` `with`… | 只在规定位置是关键字，其他位置是普通标识符                                                                    |
| 反引号 `` `…` ``           | 原始命令[逃生舱](/zh/reference/commands#原始命令逃生舱)                                                       |

## 决定绝大多数情况的规则

1. **只有调用看“紧贴”。** `foo(a)` 是调用，`foo (a)` 不是——空白之后的 `(` 要么开启坐标原子，要么直接报错。语言其余部分对空白不敏感。
2. **看位置，不看拼写。** `at`、`tick`、类型名等只在规定位置是关键字，其他位置一律是普通标识符，因此 `tag`、`team`、`tick` 这类命令名照常可用。
3. **看形式，不看标点，判断语句还是表达式。** `let`、赋值、`while`、`for`、`repeat`、`execute`、命令、`return` 是语句（无值）；其余都是表达式。`{ }` 块的值就是它最后一个表达式，因此函数末尾可以省略 `return`——见[控制流与作用域](/zh/reference/control-flow#语句与表达式)。
