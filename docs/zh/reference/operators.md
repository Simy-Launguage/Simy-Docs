# 运算符

**运算符**是把若干值组合成一个新值的符号。被运算的值叫**操作数**，像 `1 + 2` 这样的一段叫**表达式**。你通常会在 `let`、赋值语句，以及 `if` / `while` 的条件里用到运算符。

本页列出 Simy 支持的全部运算符、用大白话解释它们的含义，以及多个运算符同时出现时的结合规则。

## 算术运算符

用于数字（`num`、`float`），算出一个新数字。

| 运算符 | 名称 | 含义               | 示例 → 结果    |
| :----- | :--- | :----------------- | :------------- |
| `+`    | 加   | 两个数相加         | `3 + 2` → `5`  |
| `-`    | 减   | 左数减右数         | `5 - 2` → `3`  |
| `*`    | 乘   | 两数相乘           | `3 * 4` → `12` |
| `/`    | 除   | 左数除以右数       | `10 / 2` → `5` |
| `%`    | 取余 | 相除之后剩下的余数 | `7 % 2` → `1`  |

`%`（读作“取余”或“求模”）给出除法后的**余数**：`7 % 2` 得 `1`，因为 7 除以 2 得 3 余 1。它很适合表达“每 N 次做一次”：

```simy
if counter % 10 == 0 {
    tellraw @a "十的倍数"
}
```

## 比较运算符

比较两个值，产出一个**布尔值**——要么 `true`（真），要么 `false`（假）。这个结果正是 `if` 与 `while` 用来判断的东西。

| 运算符 | 名称     | 含义                   | 示例 → 结果        |
| :----- | :------- | :--------------------- | :----------------- |
| `==`   | 等于     | 两个值相同吗？         | `1 == 1` → `true`  |
| `!=`   | 不等于   | 两个值不同吗？         | `1 != 2` → `true`  |
| `<`    | 小于     | 左边更小吗？           | `1 < 2` → `true`   |
| `>`    | 大于     | 左边更大吗？           | `2 > 1` → `true`   |
| `<=`   | 小于等于 | 左边更小，或者相等吗？ | `2 <= 2` → `true`  |
| `>=`   | 大于等于 | 左边更大，或者相等吗？ | `1 >= 2` → `false` |

::: warning `=` 不是 `==`
`=` 用来**存值**（`let x = 1`）；`==` 用来**问问题**（“这两个相等吗？”），回答 `true` / `false`。把这两个搞混是初学者最常见的错误。
:::

```simy
if counter >= 100 {
    tellraw @a "连击达标！"
}
```

::: info `!=` 的两种含义
在选择器以外，`!=` 用于比较两个值；在选择器参数里它同样表示“不等于”（例如 `@e[type!=zombie]`）——见[命令与 Minecraft 原子](/zh/reference/commands)。
:::

## 逻辑运算符

用于组合布尔值。`&&` 和 `||` 通常写在两个条件之间。

| 运算符 | 名称      | 含义                     | 示例 → 结果                |
| :----- | :-------- | :----------------------- | :------------------------- |
| `&&`   | 与（AND） | **两边都**为真时才为真   | `true && false` → `false`  |
| `\|\|` | 或（OR）  | **至少一边**为真时就为真 | `true \|\| false` → `true` |
| `!`    | 非（NOT） | 取反                     | `!true` → `false`          |

```simy
if counter > 0 && timer > 0 {
    timer -= 1
}
```

> `&&` 和 `||` 有**短路**特性：只有当右边会影响结果时才去计算它。`a && b` 中若 `a` 已为 `false`，`b` 就不算了；`a || b` 中若 `a` 已为 `true`，`b` 也不算。

## 赋值运算符

赋值把一个值**存进**变量。简写形式是在变量自身的基础上更新；被更新的变量必须声明为 `mut`。

| 运算符 | 名称       | 含义                   | 等价于      |
| :----- | :--------- | :--------------------- | :---------- |
| `=`    | 赋值       | 把右边的值存进变量     | —           |
| `+=`   | 加后赋值   | 把变量加上这个值       | `x = x + n` |
| `-=`   | 减后赋值   | 把变量减去这个值       | `x = x - n` |
| `*=`   | 乘后赋值   | 把变量乘上这个值       | `x = x * n` |
| `/=`   | 除后赋值   | 把变量除以这个值       | `x = x / n` |
| `%=`   | 取余后赋值 | 把变量换成相除后的余数 | `x = x % n` |

```simy
let mut timer = 5
timer -= 1        // timer 现在是 4
@s.score += 1     // 分数加一
```

## 成员访问与函数调用

| 运算符 | 名称     | 含义                   | 示例                          |
| :----- | :------- | :--------------------- | :---------------------------- |
| `.`    | 成员访问 | 读取某个值的属性       | `target.health`               |
| `()`   | 调用     | 运行一个函数，可带参数 | `distance_multiplier(victim)` |

`foo(a)`（带括号）是**函数调用**；`foo a b`（不带括号）是**命令**——见[命令与 Minecraft 原子](/zh/reference/commands)。

## 一元运算符

**一元**运算符只作用于它右边的一个值。

| 运算符 | 名称 | 含义                         | 示例    |
| :----- | :--- | :--------------------------- | :------ |
| `-`    | 取负 | 把数字的符号翻转             | `-3`    |
| `+`    | 正号 | 显式标记数字为正（很少需要） | `+3`    |
| `!`    | 非   | 把布尔值取反                 | `!done` |

## 优先级与结合性

当一个表达式里出现多个运算符时，**优先级**决定先算哪一个；**结合性**决定同一优先级的运算符如何分组。

由高到低：

| 优先级    | 运算符            | 含义           | 结合性 |
| :-------- | :---------------- | :------------- | :----- |
| 1（最高） | `.`               | 成员访问       | 左     |
| 2         | `()`              | 调用           | 左     |
| 3         | `!` `-` `+`       | 一元           | 右     |
| 4         | `*` `/` `%`       | 乘 / 除 / 取余 | 左     |
| 5         | `+` `-`           | 加 / 减        | 左     |
| 6         | `<` `>` `<=` `>=` | 比较           | 左     |
| 7         | `==` `!=`         | 相等性         | 左     |
| 8         | `&&`              | 与             | 左     |
| 9（最低） | `\|\|`            | 或             | 左     |

因为 `*` 的优先级高于 `+`，下面这个表达式：

```simy
let total = 1 + 2 * 3
```

等于 `1 + (2 * 3) = 7`，**而不是** `(1 + 2) * 3 = 9`。拿不准时，用圆括号 `( )` 明确写出你想要的顺序：

```simy
let total = (1 + 2) * 3   // 9
```

*左*结合意味着同级运算符从左往右分组：`a - b - c` 相当于 `(a - b) - c`。
