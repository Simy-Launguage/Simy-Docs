# 命名与命名空间

::: info 由 lint 与 codegen 负责，不改语法
以下规则 **不改变语法**，由 **lint（转译器前端）** 与 **codegen** 负责强制。
:::

| 对象     | 约定               | 归属 |
| :------- | :----------------- | :--- |
| 函数名   | 强制 `snake_case`  | lint |
| 组件名   | 强制 `CamelCase`   | lint |
| 变量名   | 大小写自由         | —    |
| 文件路径 | 强制小写           | lint |
| `_` 前缀 | 允许，标记“未使用” | lint |
| 调用 `(` | 紧贴被调用者       | fmt  |

## 生成命名空间

**生成命名空间**与用户标识符空间**天然隔离**：

| 用途                        | 前缀      |
| :-------------------------- | :-------- |
| 生成的计分板目标 / 内部数据 | `#simy/…` |
| 生成的函数、标签等资源      | `simy:…`  |

由于 `#` 与 `simy:` 均不在公开标识符字符集内，用户无法写出同名冲突；
用户手写 `simy:xxx` 会由 lint 报错（保留命名空间）。
